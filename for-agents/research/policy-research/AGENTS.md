# AGENTS.md

These rules apply under `for-agents/research/policy-research/`.

Status: Binding

## Purpose

This directory is an advisory research bundle for the policy, Markdown, HTML,
and meta-policy pivot. It preserves the handoff, source-backed report, captured
repo files, snapshots, and experiments that inform future policy work.

Files here are evidence and working context. They are not live project policy,
runtime source, installed helper tooling, or generated output for normal repo
use unless a reviewed policy surface explicitly promotes them.

## Captured Inputs

- `current/` contains old live repo files captured for research comparison.
- `snapshots/` contains historical baselines captured for comparison.
- `experiments/` contains sketches, generated examples, prompt experiments,
  and helper scripts preserved as evidence.
- `MANIFEST.md` describes the original research fileset archive.

## Editing Rules

- Preserve captured inputs unless the task explicitly asks to annotate,
  supersede, or restructure them.
- Prefer adding notes, addenda, or report edits over silently rewriting captured
  source material.
- Keep examples and experiments clearly non-binding.
- If promoting a finding, update the live policy/doc surface and link back to
  the relevant research artifact.
